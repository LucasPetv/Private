# Lucas' Gaming Portal 🎮

Eine persönliche Gaming-Webseite mit eingebetteten Spielen und einem passwortgeschützten Admin-Bereich.

## Features

- **Eingebettete Spiele:**
  - 🐍 Snake - Der Klassiker
  - ❌⭕ Tic-Tac-Toe - Spiele gegen einen Freund
  - 🧠 Memory - Teste dein Gedächtnis

- **Game Links:** Sammlung von Verlinkungen zu weiteren Online-Spielen

- **Admin-Bereich:** Passwortgeschützte Verwaltung der Game-Links
  - Links hinzufügen
  - Links löschen

## Nutzung

1. Öffne die Webseite über GitHub Pages
2. Spiele die eingebetteten Spiele direkt auf der Seite
3. Besuche weitere Games über die Verlinkungen

### Admin-Bereich

1. Klicke auf "Admin" in der Navigation
2. Melde dich mit dem Passwort an (Standard: `admin123`)
3. Verwalte deine Game-Links

> **Hinweis:** Das Passwort kann in der Datei `js/admin.js` geändert werden. Da dies eine statische Seite ist, ist der Schutz nur eine einfache Barriere und nicht für sensible Daten geeignet.

## Technologien

- HTML5
- CSS3 (mit Animationen und modernem Design)
- Vanilla JavaScript
- localStorage für die Link-Verwaltung

## Lokale Entwicklung

Einfach die `index.html` Datei in einem Browser öffnen.
